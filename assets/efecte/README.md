Copii sunetul în folderul ăsta cu EXACT numele de mai jos (orice format: mp3/wav/ogg/m4a).

freesound.org (CC0), pixabay.com/sound-effects. Caută: „air horn effect", „vine boom",
„drum roll", „crowd cheer short", „cartoon pop".
