# 🎲 SUNETE COMICE RANDOM — arunci fișierele aici și gata

Orice fișiere audio (mp3/wav/ogg). Fără nume speciale, fără configurare.

Ce fac: editorul alege 2-3 la ÎNTÂMPLARE per episod și le pune în puncte sigure
(niciodată pe intro, momentul maxim sau final). Fiecare episod iese altfel.

Idei de căutat (gratuit, fără copyright — freesound.org CC0 / pixabay.com/sound-effects):
bambus „bamboo hit" · „bone crack" · „metal pipe falling" (țeava) · „bruh" ·
„vine boom" · „boink" · „cartoon slip" · „sad trombone" · „wilhelm scream" (scurt!)

Regula: sunete SCURTE (sub 1.5s). Sunt accente de comic, nu melodii.

════════════════════════════════════════════
🎯 MOD PRECIS (cu faster-whisper activ): pune prefix numelui și sunetul va fi
POTRIVIT contextului, nu doar random:
  fericit_yay.mp3   → sună când zici „AM PRINS!", „bravo!", „am reușit!"
  cadere_os.mp3     → sună când zici „a căzut!", „doare!", „s-a lovit!"
  speriat_hop.mp3   → sună când zici „ce frică!", „hop!"
  fără prefix (ex: bambus.mp3) = pool generic, random în puncte sigure

Poți avea mai multe per categorie: fericit_cheer.mp3, fericit_tada.mp3...
