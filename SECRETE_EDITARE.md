# SECRETELE DE EDITARE (stil MrBeast) — și UNDE-S deja active la tine

Regula mamă: **1 video nebun de bun > 10 video-uri medii.** Mai bine 1 episod perfect dintr-un
live decât 8 tăieri egale. (de-asta ai poarta de elită + motiv de existență)

| Secretul | Ce înseamnă | Unde e în PIPELINE-ul tău (pornit, automat) |
|---|---|---|
| **30 secunde = totul** | ~30% din oameni mor în primele 30s; fiecare % = diferența 2K vs 10M views | COLD_OPEN 8s: episodul pornește la C−2.8s, CHIAR ÎN explozie. Fără „salut, bine ați venit" |
| **Hook în primele 5s** | promite ceva ULUITOR imediat, nu la minutul 3 | Titlul AI = promis=livrat; primul text galben = tensiunea momentului maxim |
| **Zero aer mort** | Orice secundă care nu întreține = scoasă. Nicio excepție | comprima_zone_moarte (goluri ≥12s tăiate din mijloc) + FINAL ELASTIC (coada plictisitoare tocită) |
| **Re-hook la 10-20s** | schimbă ceva vizual/sonor constant, altfel pleacă | SFX pe evenimente reale (al TALE acum, din sunete_mele/) + text galben + confetti + cartelă |
| **Sunetul = 50% din video** | reacțiile SE VÂND prin audio: crack, boom, yay exact pe context | sunete_mele/ (folderele tale) + categorii fericit/cadere/speriat pe transcript |
| **Poveste, nu playlist** | setup → tensiune → CLIMAX → rezolvare | Povestea: intro 8s → SETUP → DEZV → MAXIM la ~minut 2 → CTA |
| **Promis = livrat** | titlul e un contract. Clickbait fals = canal mort | apel AI nr.2 strict: titlul trebuie dovedit din ce se vede |
| **CTA înainte de final** | outro-urile ucid retenția; cere like ÎNAINTE de vârf să se termină | CTA-ul intră la final-5s, coada moartă tăiată |
| **Iterează fără milă** | publică → măsoară → taie ce nu merge → repeta | calibrare după fiecare live real + /invata (regulile tale intră instant în AI) |

## Ce mai poți fura din mana lor (de aplicat la upload, nu în editare):
- **Thumbnail-ul = a 2-a promisiune**: o față + un obiect + 3 cuvinte max. Miniaturile tale = cadru REAL din momentul maxim + logo (de-asta le facem așa).
- **Publică constant, nu perfect** — algoritmul premiază ritmul. Fluxul tău: live → episoade → upload, fără scuze.
- **Primele 3 cuvinte din titlu trebuie să apese pe teama de a rata** („AM GASIT PRIMUL...", „L-AM PRINS!...").
